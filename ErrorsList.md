# Эндпоинт GET api/users

## 401 Unauthorized
Ошибка аутентификации. Возникает при отсутствии, недействительности или истечении срока действия JWT-токена в заголовке Authorization.

```json
{
  "statusCode": 401,
  "message": "Ошибка аутентификации."
}
```

## 404 Not Found
Пользователь с указанным идентификатором не найден. Идентификатор извлекается из JWT-токена.

```json
{
  "statusCode": 404,
  "message": "Пользователь с id = 00000000-0000-0000-0000-000000000000 не найден"
}
```

# Эндпоинт POST api/users

## 400 Bad Request
Тело запроса содержит невалидный JSON, или данные не могут быть десериализованы (например, невалидный тип данных).

```json
{
  "type": "https://tools.ietf.org/html/rfc9110#section-15.5.1",
  "title": "One or more validation errors occurred.",
  "status": 400,
  "errors": {
    "": ["Expected a string, got start of object."]
  }
}
```

## 422 Unprocessable Entity
Ошибка валидации входных данных. Возникает при нарушении правил FluentValidation:

- **Email** пустой: "Электронная почта не должна быть пустой"
- **Email** не является адресом электронной почты: "Строка не является адресом электронной почты"
- **Email** уже зарегистрирован: "Пользователь с подобным адресом уже существует"
- **Password** короче 8 или длиннее 33 символов: "Пароль должен быть больше 8 и меньше 34 символов"
- **Password** не содержит спецсимволов: "Пароль должен содержать спецсимволы"
- **Password** не содержит заглавную букву: "Пароль должен содержать заглавную букву"
- **FirstName** пустое: "Имя не должно быть пустым"
- **LastName** пустая: "Фамилия не должно быть пустым"

```json
{
  "statusCode": 422,
  "message": "Email - Пользователь с подобным адресом уже существует;Password - Пароль должен содержать спецсимволы"
}
```

# Эндпоинт POST api/users/refresh

Ошибка аутентификации. Возникает в следующих случаях:
- Отсутствует cookie refresh_token
- Refresh-токен не найден в хранилище

- Refresh-токен отозван
- Пользователь, связанный с refresh-токеном, не найден

# Эндпоинт POST api/transactions

## 400 Bad Request
Тело запроса содержит невалидный JSON, или данные не могут быть десериализованы (например, невалидный Guid для SourceAccountId/DestinationAccountId, невалидный тип для Amount).

```json
{
  "type": "https://tools.ietf.org/html/rfc9110#section-15.5.1",
  "title": "One or more validation errors occurred.",
  "status": 400,
  "errors": {
    "": ["Expected a string, got start of object."]
  }
}
```

## 401 Unauthorized
Ошибка аутентификации. Возникает при отсутствии, недействительности или истечении срока действия JWT-токена.

```json
{
  "statusCode": 401,
  "message": "Ошибка аутентификации."
}
```

## 404 Not Found
Возникает в следующих случаях:
- Пользователь с указанным идентификатором не найден (идентификатор из JWT-токена)
- Исходный счёт (SourceAccountId) не найден
- Счёт-получатель (DestinationAccountId) не найден

```json
{
  "statusCode": 404,
  "message": "Пользователь с id = 00000000-0000-0000-0000-000000000000 не найден"
}
```

## 409 Conflict
Нарушение лимита баланса. Возникает в следующих случаях:
- Баланс исходного счёта (SourceAccountId) опускается ниже установленного лимита
- Баланс счёта-получателя (DestinationAccountId), не являющегося хранилищем, превышает установленный лимит

```json
{
  "statusCode": 409,
  "message": "Баланс конечной точки транзакции c id = 00000000-0000-0000-0000-000000000000 вышел за установленный лимит"
}
```

## 422 Unprocessable Entity
Ошибка валидации входных данных. Возникает при нарушении правил FluentValidation:

- Ни SourceAccountId, ни DestinationAccountId не указаны: "По крайней мере одно из свойств (SourceAccountId или DestinationAccountId) должно иметь значение."
- SourceAccountId и DestinationAccountId совпадают: "Нельзя создать Transaction, где SourceAccountId и DestinationAccountId имеют одинаковые значения"
- Amount меньше или равно нулю: "Значение должно быть больше нуля"
- SourceAccountId указан для области трат (IsStorage=false): "Область трат не может быть указана как SourceAccount"
- DestinationAccountId указан для области трат с попыткой корректировки баланса: "Нельзя скорректировать баланс области трат"

```json
{
  "statusCode": 422,
  "message": "Amount - Значение должно быть больше нуля;SourceAccountId - Область трат не может быть указана как SourceAccount"
}
```

- Периоды пересекаются: "Периоды не должны пересекаться. Конец первого периода должен быть строго меньше начала второго периода"
- Превышен лимит временных единиц: "Превышен максимальный лимит временных единиц: Day <= 36500, Month <= 1200, Year <= 100"

```json
{
  "statusCode": 400,
  "message": "Периоды не должны пересекаться. Конец первого периода должен быть строго меньше начала второго периода"
}
```

## 401 Unauthorized
Ошибка аутентификации. Возникает при отсутствии, недействительности или истечении срока действия JWT-токена.

```json
{
  "statusCode": 401,
  "message": "Ошибка аутентификации."
}
```

## 404 Not Found
Пользователь с указанным идентификатором не найден. Идентификатор извлекается из JWT-токена.

```json
{
  "statusCode": 404,
  "message": "Пользователь с id = 00000000-0000-0000-0000-000000000000 не найден"
}
```
